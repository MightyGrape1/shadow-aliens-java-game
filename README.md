# Shadow Aliens – Java Space Shooter

A 2D space shooter game developed independently in Java as part of a university software development project.

## Gameplay

![Shadow Aliens Gameplay](screenshots/gameplay.png)

The game features multiple enemy types, different attack patterns, power-ups and wave-based progression.

## Key Features

- **Player Controls:** Move the spaceship and shoot incoming enemies.
- **Enemy Behaviours:** Multiple enemy types, including regular, strafing and shooting enemies.
- **Power-up System:** Collect items to gain shields, extra lives, faster shooting and increased movement speed.
- **Combat Mechanics:** Collision detection, projectile handling and enemy attacks.
- **Game Progression:** Multiple waves, scoring, player health management and game-over handling.
- **Game States:** Start, pause, restart, victory and failure states.

## Technical Details

- **Language:** Java
- **Framework:** Bagel
- **Programming Concepts:** Object-oriented programming, inheritance and polymorphism
- **Configuration:** External properties file for game settings and wave configuration

The project uses the Bagel framework and some starter code provided by the course. I independently implemented and extended the game's core functionality and gameplay mechanics.
